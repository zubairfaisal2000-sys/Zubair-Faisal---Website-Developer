# Zubair Faisal – Portfolio Website

Personal portfolio for Zubair Faisal, Business & Portfolio Website Developer.

## Files
- `index.html` – page structure, content and JavaScript
- `style.css` – all styling (colors are variables at the top, under `:root`)
- `logo.png` – logo (also embedded in `index.html`)

## Deploy on Vercel
1. Put these files in one folder.
2. On vercel.com choose **Add New > Project** and upload the folder.
3. Deploy.

## Contact form (inside `index.html`)
- **Send Message** opens WhatsApp (+92 302 2051748) with the message filled in.
- **Send To Mail** sends the message to zubairfaisal2000@gmail.com through FormSubmit. After deploying, send one test message and click the confirmation link FormSubmit emails you. Messages only arrive after that.
- **Send To Instagram Instead** opens a chat with @zuba.irfreelancer.

To change these, search `index.html` for `var WA=` (WhatsApp, Instagram, email) and `formsubmit.co`.

## Editing
- Projects: search `Featured Work` in `index.html`.
- Colors: edit the `:root` variables at the top of `style.css`.
